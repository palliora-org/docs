Build on Palliora to run private, verifiable computation from your own code: call a model privately, publish data or a model for others to pay for, or wrap Palliora behind an API your users already know.

| You want to…                                                            | Go to                                                                                                    |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Get a result back in five minutes                                       | [Quickstart](/build/quickstart)                                                                       |
| Call a model, or wrap Palliora behind a chat-completions-compatible API | [Palliora AI: Build](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/ai/build/README.md) |
| Keep inputs and outputs encrypted end to end                            | [Guides: Encrypted compute](/build/guides/encrypted-compute)                                          |
| Store data                                                              | [Guides: Store data](/build/guides/store-data)                                                        |
| Publish a model or workload                                             | [Guides: Compute Artifacts, publish and run](/build/guides/compute-artifacts)                         |
| Look up a function, endpoint, command or error                          | [Reference](/build/reference)                                                                         |
| Have a coding agent build it                                            | [Coding agents](/build/coding-agents)                                                                 |
| Integrate private trading or private AI                                 | [Products](/products/products)                                                                        |

You should know three ideas first: [Compute Contracts](/learn/concepts/compute-contracts), [Guardians](/learn/concepts/guardian) and [Compute Artifacts](/learn/concepts/compute-artifacts). If not, read [How Palliora works](/learn/how-it-works) first. It takes five minutes.

Everything here runs on Manas, Palliora's public testnet, through `@palliora.org/chainsdk`. Palliora DeFi already reaches Ethereum and Hyperliquid.

"Agent" in the Build section means a published Compute Artifact, not an AI coding assistant. Different thing, same word.
