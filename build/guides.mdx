Runnable walkthroughs, each building something real against the live testnet, not isolated snippets.

* [Encrypted compute](/build/guides/encrypted-compute): threshold-encrypted inference. Your prompt and answer stay hidden from everyone but you and the compute node that runs the model.
* [Store data](/build/guides/store-data): submit data to Palliora's Data Availability layer and read it back. Public (plaintext).
* [Compute Artifacts: publish and run](/build/guides/compute-artifacts): package a model or function once, and reference it from any number of Compute Contracts afterward.

Looking to call a model, or wrap Palliora behind a chat-completions-compatible endpoint? Those guides moved to the [Palliora AI](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/ai/build/README.md) section: [Call a model](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/ai/build/guides/call-a-model.md) and [Build a chat-completions-compatible service](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/ai/build/guides/chat-completions-service.md).
