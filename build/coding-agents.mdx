title: "Coding Agents"
---

A growing share of the code written against these docs is written by an AI coding agent acting on a person's behalf. These pages cover both sides of that:

* [Build with a coding agent](/build/coding-agents/build-with-a-coding-agent): for the person directing the agent. How to point one at Palliora and get a working integration back.
* [For agent-assisted developers](/build/coding-agents/for-agent-assisted-devs): for the agent itself. What's safe to assume, and where to look so it doesn't have to guess.
* [`palliora.skill.md`](/build/coding-agents/palliora.skill): a single downloadable skill file. Drop it into a coding agent's skills or context directory.

"Coding agent" on these pages always means an AI coding assistant. It has nothing to do with Palliora's own Agent concept, a published Compute Artifact, covered in [Compute Artifacts: publish and run](/build/guides/compute-artifacts).
