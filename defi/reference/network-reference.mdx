## Disclosure network

One revoker serves both mainnet pools. Revoker id 0 is registered and active on Ethereum and on HyperEVM. Decom guardians hold the shares of the disclosure key. The revoker keeps a report of what it de-anonymized on Palliora DA. Only the revoker, or any third party the revoker grants access to, can read it. See [Accountable privacy and disclosure](/defi/learn/concepts/accountable-privacy-and-disclosure) and [Palliora integration](/defi/learn/concepts/palliora-integration).

## How these values were read

Each value came from a read-only call to the network, so you can repeat it. This example reads the Ethereum pool's limits with [Foundry](https://getfoundry.sh):

```bash
POOL=0x4cEcb7F987d220fe2E8608149fa76ed6d021Ad11
RPC=https://ethereum.publicnode.com

cast call $POOL "paused()(bool)" --rpc-url $RPC
cast call $POOL "minDepositUsd()(uint256)" --rpc-url $RPC
cast call $POOL "getAsset(uint24)((uint24,uint8,address,bool,uint8,address,uint8))" 65538 --rpc-url $RPC
cast call $POOL "isAdaptorSupported(address)(bool)" 0x57B9D7602497d8a78eE06B1Eba6cB37E8E3E0738 --rpc-url $RPC
```

Dollar amounts on the pool use 6 decimals, so `10000000` means $10. If a value here differs from the network, the network is right.
