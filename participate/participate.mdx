---
title: "Participate"
---

Run infrastructure for Palliora, rather than building on top of it or using an app built on it.

* [Become a Guardian](/participate/become-a-guardian): hold key shares, coordinate data access and computation, review disclosure requests, and earn fees for it.
* [Become a Validator](/participate/become-a-validator): secure the coordination ledger, and earn staking rewards and transaction fees.
* [Run a node on a TEE](/participate/run-a-node-on-a-tee): run your Guardian or Validator node inside a hardware-attested Trusted Execution Environment instead of a plain VM.

See [Guardian](/learn/concepts/guardian) and [Validator](/learn/concepts/validator) for what each role actually does before you provision hardware for it.

The Manas network is open: anyone can join or leave as a Guardian or Validator without permission.
