This section is for using Palliora and the apps built on it, no coding required. Everything here runs on Manas, Palliora's public testnet, with free test tokens. If you want to build something yourself instead, see [Build](/build/build).

* [Account management](/use/account-management): log in with a wallet or an email address.
* [Get test tokens](/use/get-test-tokens): claim PALI on the testnet faucet.
* [Upload your data](/use/upload-your-data): publish data or a model and set a price for access.
* [Try the demo app](/use/demo-apps): the Palliora DeFi demo app.

Looking to try the Palliora AI demo? See [Try the demo app](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/ai/use/demo-apps.md) in the [Palliora AI](/products/palliora-ai) section.
