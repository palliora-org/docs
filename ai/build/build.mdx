Palliora AI runs on the same `@palliora.org/chainsdk` as the rest of Palliora. There's no separate AI SDK; building on Palliora AI means using the chain SDK's inference calls, plain or encrypted.

This section is for developers and for AI coding agents. If you only want to use the demo app, go to [Try the demo app](/ai/use/demo-apps).

| You want to…                                           | Go to                                                                                                                  |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Send a plain inference request                         | [Call a model](/ai/build/call-a-model)                                                                              |
| Keep the prompt and answer private                     | [Encrypted compute](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/build/guides/encrypted-compute.md) |
| Wrap Palliora behind a chat-completions-compatible API | [Build a chat-completions-compatible service](/ai/build/chat-completions-service)                                   |
| Look up a function, endpoint or error                  | [Build: Reference](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/build/reference/README.md)          |
| Have a coding agent build it                           | [For agent-assisted developers](/ai/build/for-agent-assisted-devs)                                                  |

## Before you start

Read [How Palliora works](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/learn/how-it-works.md) and [Compute Contracts](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/learn/concepts/compute-contracts.md) if you haven't. Everything below assumes you know what a Compute Contract and a Guardian group are. The [core Quickstart](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/build/quickstart.md) is the fastest way to get those ideas under your fingers before coming back here.
