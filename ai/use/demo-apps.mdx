Palliora AI's demo app, AI Workbench, is live at [**ai.palliora.org**](https://ai.palliora.org/). It looks and works like any modern AI chat app: you type, it responds, and it can search the web, fetch a page, and use other tools. Underneath, every model call and every tool call runs as its own [Compute Contract](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/learn/concepts/compute-contracts.md), and every turn produces a [provenance](/ai/learn/concepts/provenance) record: which model ran, which tools were called, and a reference to the agreement that coordinated each one.

Signing in creates your own Palliora identity, so every request is signed by you, not by a shared service account. See [Palliora AI](https://github.com/palliora-org/palliora-docs-with-ai/tree/main/products/palliora-ai.md) for how the product works.

## Get started

1. **Open the app.** Go to [ai.palliora.org](https://ai.palliora.org/).
2. **Sign in with your email.** No wallet needed. This creates your Palliora identity, used to sign every request you make from the app.
3. **Redeem a coupon code.** New accounts start without a balance. In the chat box, type `/redeem CODE`, replacing `CODE` with the code you were given. This funds your account so you can start chatting.

   Don't have a code? Email **[ai@palliora.org](mailto:ai@palliora.org)** to get one.
4. **Start chatting.** Ask a question, or try a prompt that needs a tool, like a web search. Each response is backed by a Compute Contract you can inspect.
